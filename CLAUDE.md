# Projekt: Searchbrain

## Ziel
Ein Tool, das junge Unternehmen (Startups) findet, nach Kriterien
filtert und kurz zusammenfasst. Es ist ein Lern- und Vorzeigeprojekt.

## Funktionen (erste Version)
- Startups über Websuche bzw. eine Datenquelle finden
- Pro Startup: Name, Beschreibung, Branche, Land, Link
- Ergebnisse einer Suchanfrage in einer Liste ausgeben
- Spätere Ausbaustufe: Chat-Oberfläche, in der ich Fragen stelle

## Technik
- Sprache: Python (anpassen, falls anders gewünscht)
- KI-Modell über API: NVIDIA (build.nvidia.com), Zugang per .env
- API-Keys nur in .env, nie im Code oder in Git
